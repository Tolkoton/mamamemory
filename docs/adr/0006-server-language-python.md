# ADR-0006: Мова сервера — Python

## Status

ACCEPTED

Date: 2026-11-05

## Context and Problem Statement

M3 обирає мову сервера. Змінити її потім означає переписати сервер, тож це однобічні двері. Критик M3 поставив на неї MASTER_CRITIC_RATIFY (.engine/architecture/reviews/m3-critic.md, раунд 9).

## Considered Options

- **A. Python 3.12.** PoC 1–2 перевіряли саме Python-бібліотеки Google через `eu`; є офіційні клієнти для Calendar, Tasks, Firestore і Cloud Storage; ланцюжок перевірок движка (ruff, mypy, pytest) працює без налаштувань.
- **B. TypeScript/Node.** Одна мова з застосунком і зазвичай швидший холодний старт. Але PoC довелося б повторювати на Node SDK, а для перевірок движка — налаштовувати власні команди. Різниця в ціні не виміряна, за одної користувачки це центи.

## Decision Outcome

Обрано A. Рішення власника, дослівно: «Так, значить, мова сервера Python. M2 і M3 затверджую.» (2026-11-05, розмова з master-architect).

## Звірка з цілями
- служить: G1, G2, G3, G4, G5, D1
- вибір між варіантами розв'язав: принципи не розрізняють варіантів (P1, C6 — різниця в центах, не виміряна); вирішують перевірені PoC бібліотеки й інструменти
- не-цілі й обмеження: C1 — бібліотеки Google через eu перевірено в PoC; C2 — усе Google
