- Раунд 6 — REVISE: BLOCKING — «перекласти» переграє описи по матеріалу: ~60 викликів 3.8 Flash ≈ 6 хв, понад таймаут Cloud Run → адресат — одне оновлення, джерело — один виклик з усіх текстів, якість — перевірка каркаса; загальний дедлайн на кожен ланцюжок викликів. NOTE: обмеження задач і абсолютний кінець горизонту в чернетці; переходи зі «записується» — лише за тим самим часом початку; запис задачі — два кроки (подія + закриття в Tasks), порожня решта → «записано»; P-DISCONNECT; власник затверджує мову (Python), версія — архітектора.
- Раунд 7 — REVISE: BLOCKING — після перезавантаження застосунку Android-ом незакрите «створити справу?» зникало з екрана, і фото мовчки не потрапляло в справу (G3) → маршрут «відкриття застосунку» повертає незакриті питання з Firestore зі своїми reply_to; «створити справу?» — окремо на кожен матеріал; тест node. NOTE: крок розстановки під час показу, мітка assistant на схемі, повтори лише для читань і Gemini, закриття в Tasks без нового «так», межа дедлайну й таймаути Firestore/GCS, каталог матеріалів для «перекласти», порожня справа лишається, облікові дані — функцією, таймаут Cloud Run — одне значення для Сонька, маніфест, дубль речення прибрано, два виклики паралельно.
