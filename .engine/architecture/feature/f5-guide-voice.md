# Feature f5-guide-voice — F5. Гайд, «прочитай», мова — decomposition

## Goal
Асистент сам коротко розказує, що вміє і як з ним працювати (G5): на першому відкритті після викладки F5 і щоразу на
«що ти вмієш?». Біля кожної відповіді — значок «прочитай»: на натиск асистент озвучує цю відповідь українською (C4:
голосом — «по запиту, а не кожен раз»). Мова розмови тримається під акаунтом (поки лише українська, C8: «закласти
можливість її змінити»).

## Acceptance criteria (PROVISIONAL — owner ratification pending; ціна відкату — перепланувати slice)
- AC1. На першому відкритті застосунку після викладки F5 мама бачить короткий гайд (до ~6 рядків: як сказати задачу,
  сплануй тиждень, нотатка й фото у справу, «прочитай», перепитування); далі гайд не показується сам (G5; INDEX F5 —
  позначка «гайд показано» під акаунтом).
- AC2. На «що ти вмієш?» / «як з тобою працювати?» — той самий гайд (G5).
- AC3. Біля кожної відповіді асистента — значок «прочитай» (🔊); натиск відтворює цю відповідь голосом; без натиску
  нічого не звучить (C4).
- AC4. Мова розмови — поле під акаунтом (за замовчуванням `uk`); розпізнавання, озвучення й гайд беруть її звідти (C8).

## Build parameters (PROVISIONAL — owner ratification pending)
- Budgets: текст для озвучення — увесь (власник 2026-11-12: «Суть має бути вся»; межу 1 500 прибрано, speak-control); голос — Gemini-TTS через `eu-texttospeech`
  (PoC 2: 10/10, ≈5 с); формат — OGG Opus (Chrome на Android).
- Policies: помилка озвучення — «Не вдалося озвучити.» без звуку; у журнал — лише тип помилки (C1).
- Autonomy: власник — «запускай f1–f5»; дії в хмарі — через Сонька.
- Principles: C4 — озвучення лише на прохання (ніякого автоозвучення); P1 — гайд — текст без моделі.

## Звірка з цілями
- служить: G5 (AC1, AC2), C4 (AC3), C8 (AC4).
- вибір між варіантами розв'язав: C4 (озвучення лише на прохання), P1 (гайд без моделі), C1 (TTS лише EU-адреса).
- не-цілі: N5 — гайд не сповіщення, лише коли мама відкрила застосунок.

## Slices (the DAG)
- **S1 language-setting** — delivers: `settings/profile {language: "uk"}` під акаунтом (немає документа — `uk`), читання
  через `access.language(session, store) -> str`; розпізнавання голосу (`http` → `speech`) бере мову звідти, а не з
  `config.language` · contract out: `access.language` · depends on: — · block: f5
- **S2 guide** — delivers: гайд текстом (мовою з S1; поки один текст `uk`) на першому відкритті після викладки — пункт
  без питання в `plain` незакритих питань (ніколи не останній з `reply_to`), позначка `settings/guide_shown` пишеться,
  коли `open_questions` його повертає, і її помилка не забирає інших пунктів; на намір `help` («що ти вмієш?», «як з
  тобою працювати?») — той самий гайд; `help` лишається й під питанням справ; відповідь на `other` замість застарілого
  «Поки що я вмію записати одну задачу в календар.» — «Не зрозуміла. Скажіть «що ти вмієш?» — розкажу.» ·
  `help` — у схемі маршрутизації й обробляється в `_dispatch`, але не варіант уточнення (clarify Q1 лишається); новий
  текст `other` перепечатує запечатані тести clarify, stuck-question, note-to-case, voice-edits (supersede); позначка
  пишеться, коли гайд повернуто, а не показано — загублену відповідь покриває «що ти вмієш?» ·
  contract out: `assistant.guide_text(language)`, намір `help` · depends on: S1 · **TRACER BULLET** · block: f5
- **S3 read-aloud** — delivers: `POST /api/speak {text, part}` → аудіо OGG Opus однієї частини (заголовок `X-Parts`);
  `integrations.tts.parts(text)` і `Speaker.say(part, language, *, deadline, now) -> bytes` бере код акаунта (`uk`) і
  сам перекладає в код TTS (`uk-UA`) (поправка 2026-11-11: спайк — довгий текст в один виклик не встигає, P-TTS-LONG); голос `Kore`, модель
  `gemini-2.5-flash-tts`, `eu-texttospeech.googleapis.com` (як PoC 2); значок 🔊 біля кожної відповіді — стан «озвучую…» і
  один запит за раз на відповідь · contract out: `tts.parts`, `tts.Speaker.say` · depends on: S1 · block: f5
- **S4 f5-measure** — delivers: залежність `google-cloud-texttospeech` (uv) уже в S3; Сонько вмикає Text-to-Speech API
  для сервісного акаунта Cloud Run (передумова), викладка, smoke TTS на справжньому сервісі, звіт · depends on: S1–S3
